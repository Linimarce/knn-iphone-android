# KNN-модель предсказания выбора смартфона

## О проекте
Модель машинного обучения (K ближайших соседей) предсказывает,
какой смартфон предпочитает пользователь — iPhone или Android,
на основе данных опроса.

## Файлы
- `knn_model.ipynb` — основной код с моделью
- `Предпочтение пользователей Iphone или android.csv` — данные опроса
- `requirements.txt` — зависимости

## Как запустить
1. Откройте `knn_model.ipynb` в Google Colab
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите все ячейки ноутбука

## Результат
Точность на тестовой выборке: ~80%
